# Context
JAX é uma biblioteca Python focada em "Accelerator-Oriented Array Computation" e "Program Transformation" (Seja lá o que isso quer dizer)... 
Usado em High-Performance Numerical Computing e Large-Scale Machine Learning.

**Principais atributos**:
- API muito similar com a do Numpy.
- Transformations se refere a modificar processos de: **Compilação, Batching, Automatic Differentiation e Parallelization**.


# Installation:
Para usar o potencial do **JAX** são necessários dois pacotes o $\texttt{jax}$ e o $\texttt{jaxlib}$
**OBS:** Parece haver bastante diferença para as distribuições Linux, isto é, bem mais funcionalidades, então acho que é uma boa eu instalar o dual-boot para conseguir rodar no maior potencial. Eu acho que isso acontece, porque as otimizações para rodar na GPU parecem não estar disponíveis para Windows.
