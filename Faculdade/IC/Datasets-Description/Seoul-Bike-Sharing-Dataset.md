# Properties:
This dataset main use is to predict demand for biking services
# Attribute Description:
Attribute 1 - Date in the format DD/MM/YYYY
Attribute 2 - Rented Bike Account
Attribute 3 - Hour
Attribute 4 - Temperature (Celsius)
Attribute 5 - Humidity (%)
Attribute 6 - Wind Speed (m/s)
Attribute 7 - Visibility (DON'T KNOWN THIS MEASURE)
Attribute 8 - Dew Point Temperature (Celsius) - Can be used to indicate humidity
Attribute 9 - Solar Radiation (MJ/m2)
Attribute 10 - Rainfall (mm)
Attribute 11 - Snowfall (cm)
Attribute 12 - Season
Attribute 13 - Indicates if it is a Holliday - Binary
Attribute 14 - Indicates if it is a functioning day - Binary
