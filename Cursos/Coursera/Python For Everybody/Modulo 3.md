# Escrevendo parágrafos de código:
## Program Steps or Program Flow:
- Sequential: 
```python
x = 2
print(x)
x = x + 2
print(x)
```
- Conditional:
```python
x = 5
if x < 10:
	print('Smaller')
if x > 20:
	print('Bigger')
	
print('Finis')
```
- Repeat:
```python
n = 5
while n > 0:
	print(n)
	n = n - 1
print('Blastoff!')
```
Cada trecho de código pode ser entendido como um paragrafo de um texto tentando dizer algo (que ele irá fazer).
