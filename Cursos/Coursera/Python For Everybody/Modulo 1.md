# Why program:
Os softwares são o que tornam o Hardware "burro" em algo inteligente. Entrar dentro do desenvolvimento de programas. 

Inicialmente podemos pensar que devemos desenvolver programas para descobrir coisas interessantes sobre os dados. Não é necessário ser um profissional para fazer programas funcionarem, contudo se você quer entrar mais a fundo é legal se aprofundar.

Contudo, precisamos pensar que um programa nada mais é que uma sequência de instruções pré-planejadas. Contudo, programas não corrigem erros sob demanda nativamente.

Existem tarefas que o computador é muito melhor que os humanos, contudo o contrário também é verdade.
