- Omarchy is designed for a dedicated driver - dual-booting ideally requires two disks, but a [Manual](https://learn.omacom.io/2/the-omarchy-manual/96/manual-installation) installation will provide tools for only one disk.

**Steps on installing Omarchy**:
1. Install the ISO from the site.
2. Use **balenaEtcher** (Windows/Mac) or caligula (Linux) to flash the OS into the disk.
3. Remember to deactivate **Secure Boot** and **TPM** in the BIOS.
4. Just select the boot manager to use your disk with flashed OS.
5. Follow steps.
6. Done.
