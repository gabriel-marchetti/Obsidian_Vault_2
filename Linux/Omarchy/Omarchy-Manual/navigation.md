- Everything can be done via Keyboard.

$\texttt{Super + Space}$ : Application Launcher.
$\texttt{Super + Alt + Space}$ : Omarchy Menu.
$\texttt{Super + K}$ : Cheatsheet.

$\texttt{Super + Return}$ : Open the terminal.
$\texttt{Super  + Shift + B}$ : Open the browser.

---
# Floating Window:
$\texttt{Super + T}$ : Makes the window float.
If you want to resize it or move it you will need to hold super and click the mouse buttons to do that.

There is a feature that seems to be useful, if you use $\texttt{Super + O}$ it will make the window float and make it sticky so that it will appear in every workspace.

---
# Window groups:
If you toggle $\texttt{Super + g}$ it will toggle group mode and if you open another windows it will appear in another group.

If you want to bring a Windows that is not at the group, you can use $\texttt{Super + Alt + <Arrow-Key>}$ to bring it to the group.

If you want to take it out of the group, you could do $\texttt{Super + Alt + g}$. 

---
# Clipboard Manager:
$\texttt{Ctrl + Super + v}$ : Clipboard Manager.
