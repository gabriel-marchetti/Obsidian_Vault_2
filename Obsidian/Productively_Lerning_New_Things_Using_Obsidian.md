**Danki** for creating flashcards and **Obsidian Plugin - Spaced Repetition Plugin**. 

### Spaced Repetition in Obsidian:
A primeira coisa que é modificada é adicionar um "Flashcard Tag" para o assunto de interesse que você está estudando. Além disso, ele modifica o "Separator for Inline flashcards" para ";;" uma vez que a ocorrência desse padrão é muito menos frequente e, de fato, pode se confundir quando alguns trechos de código forem aparecendo.

### Single-Note.
O primeiro exemplo será fazendo através de uma anotação dentro de um arquivo. Esse exemplo será feito dentro da anotação [[Example_Spaced_Repetition_SingleNote]] e irá mostrar como configurar um Flashcard dentro de uma anotação única. 

1) Defina um YAML-header dentro da anotação.
2) Crie uma tag dentro da extensão do plugin.
3) Coloque essa tag dentro do YAML-header.
4) Agora suas anotações estarão dentro do review-cards do tópico.



# Flashcards.
Basicamente as coisas que serão úteis para serem utilizadas são: Como configurar os **inline flashcards**, **inline reversed flashcards**, **multiline flashcards** e **multiline reversed flashcards**.
Contudo, preciso criar uma pergunta de como adicionar uma nova *tag* e linká-la dentro do YAML-header.

Relembre como criar um *tag* para adicionar um conteúdo específico dentro do painel de flashcards para spaced-repetition.
?
Para criar uma *tag* basta entrar no painel de configuração do plugin spaced-repetition e adicionar a tag.

Relembre como criar um inline flashcard
?
Um inline flashcard pode ser criado adicionando um ";;" entre a pergunta e a resposta.

Relembre como criar um multiline flashcard
?
Um multiline flashcard pode ser criado adicionando um "?" entre a linha da pergunta e a linha da resposta.

Relembre como criar um multiline reversed flashcard
?
Um multiline reversed flashcard pode ser criado utilizando um "??" entre a linha de pergunta/resposta com a linha resposta/pergunta.

Relembre como criar um inline reversed flashcard ;;; um inline reversed flashcard pode ser criado através de um ";;;".
