- Every programmer passed this phase.

- Tutorials trick you so that you actually know what you are doing, but someone else is lifting the weight.
  Coding is about 
  1) Getting Stuck.
  2) Breaking Things.
  3) Googling Stuff.
  4) Asking Questions.
  5) Slowly Piecing Things Together.
- **Days 1-3: Warmup** - 
  1) Write a python program that add two numbers.
  2) Write a python program that prints the first 3 lines of a file.
  3) For web, make a page that shows text that change when you click the button.
  4) For gamedev, put a sprite on the screen and make it move in the screen.
  5) For Machine Learning, load a dataset and print the first five rows of it.
	This are basic stuff you will do. But they gave you momentum on doing other things.
- **Days 4-7: Project 1 -**
  Make it embarrassingly simple.
  Big Projects are not affordable at this moment 
  Python: Terminal To-Do List.
  For Web: A note app that creates, edit and delete.
  For Gamedev: Pong of Flappy-Bird clone.
  For AI/ML: Sentiment Classifier if text is positive or negative.
  Focus on finishing projects.
- **Days 7: The Wall -**
  Projects don't work.
  Blank Screen and Erros are encountered by every developer.
  Pipeline of dealing with errors:
  (1) Reproduce the Bug. Twice.
  (2) Isolate the smallest chunk of code that's breaking.
  (3) Read the error message out loud.
  (4) Print Values and add Logs.
  (5) Google the exact error message.
  (6) Skim the docs.
  (7) if all fail, then ask someone.
- **Days 8-13: Project 2** - 
  A public project that you can show someone else.
  Python - Create a script that pulls weather data with an API.
  Gamedev - Small level with a score counter.
