Ele compartilha um material interessante para aprender sobre o Python:
https://programming-26.mooc.fi/

Uma das dicas que ele sugere é a de escrever um resumo de cada sentença que você estiver lendo. Para trechos de código tente escrever o trecho sem olhar para o exemplo e, além disso, tente prever as saídas das etapas intermediárias.

Dessa maneira, faça perguntas sobre os trechos de código que você escreveu e tente modificar para ver comportamentos que podem ser inesperados.
