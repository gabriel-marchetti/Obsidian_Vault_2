- Rust é uma linguagem de programação que, cada vez mais, se insere como uma linguagem amplamente usada.
- Amazon utiliza dentro projeto **Firecracker**.
- Microsoft está escrevendo algumas partes do Windows e Azure em Rust.
- Google utiliza o Rust dentro do Google e do Android.
- A ferramenta Proton desenvolvida pela Steam também utiliza Rust.
- O próprio Kernel do Linux utiliza Rust.

- A questão aqui é, quando grandes corporações adotam uma linguagem de programação nova, então há um motivo. Principalmente quando pensamos que são áreas sensíveis.

## Alguns modos de aprender sobre a linguagem Rust.
- The Rust Book - É um livro fornecido pela própria corporação do Rust.
- Rustlings - Um repositório do Github que fornece códigos com erros e você precisa descobrir.
- Rust by Example - Outro livro que também é fornecido pela Rust Foundation.
