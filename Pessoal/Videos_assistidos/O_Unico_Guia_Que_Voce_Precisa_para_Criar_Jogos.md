# Reconhecendo o Problema.
Comece pensando na criação do jogo naquilo que você é bom, isto é, pense que a questão principal do jogo deve ser focada nessa área. Por exemplo, um jogo com gráficos simples e código mais complexo. 
- Sites como o Itch.io fornecem artes e músicas gratuitas para os jogos.
- Não crie jogos complexos.
- Comece com algo pequeno, mas que te inspire.
# Primeiros Passos.
- Pense no **Nicho** e **Ferramentas**.
- Escolha um **Nicho** simples.
- NoneJam e AmdreYoung GameJam.
# Motivação.
- Determinação para terminar os jogos.
- Comece criando jogos como Hobby, desse modo é necessário encaixar isso dentro da rotina.
