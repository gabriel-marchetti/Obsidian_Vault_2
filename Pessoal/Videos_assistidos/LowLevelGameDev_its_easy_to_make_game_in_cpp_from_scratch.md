A Game Engine can boost the start of a game project. But, in a longer perspective it can introduce some overhead in development into areas such as: optimization and flavor of the game.

Three principles in making your own game without an engine.
1) Learn the language well.
2) Start making a game following a tutorial.
   Display a simple sprite into the screen.
3) Make bigger projects.
   Make clones of game you play and like
   Keep your code simple.
