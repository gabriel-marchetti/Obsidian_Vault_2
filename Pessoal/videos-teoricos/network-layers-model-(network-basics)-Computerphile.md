- Basics of Internet-Layers Model.
- OSI (Open System Interconnection), ISO (International Organization for Standardization) and TCP/IP

When the problem was stated (we want to send and receive data) it was broke down into little pieces.
![[models_side_by_side.webp|center]]

- Transport Layer - Interface for **sending** and **receiving** data.
- Network Layer - Figures out how to send data from one computer to another one (Does the whole journey).
- Data Link - It is one step of the journey, figures out how to move in the network.

Technologies for Transport Layer - TCP and UDP
Technologies for Network Layer - IPv4 and IPv6
