If you want to:
- Automate a task.
- Create a small custom Database.
- Create a specialized GUI application.
- Create a simple game
See that shell scripts are suitable for managing files and renaming them, but shell scripts are pretty bad at dealing with GUIs. This problem does not exist in Python, because you can leave the tasks that shell scripts are good to them and python handle other stuff.
In this matter we can say that python is **Extensible**, in a way that we can extend it with binary code distributed by vendors and your own code.
These process can be made by design different **modules** for python code that could be reused in future projects. 
Also it's interpretable development can save time when it comes to not having to worry about compilation and linking process.
