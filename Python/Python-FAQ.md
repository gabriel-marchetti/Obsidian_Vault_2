# Why was python created:
[[Guido-van-Rossum]] had experience implementing interpreted languages in the ABC Group at CWI, [[ABC]] was a teaching and prototyping language developed from the [[B]] language, that had the same structure as python for indentation for Block-Structure. Besides the inspiration of the [[ABC]], the [[Modula-2+]] and [[Modula-3]] were also languages that inspired how python is today. The hard structure of Amoeba distributed OS inspired [[Guido-van-Rossum]] to develop a more extensible language, then [[Python]] was created.

# What is Python good for:
By standard it comes with:
- String Processing - Regex, Unicode, Calculating difference between files
- Internet Protocols - HTTP, FTP, SMTP, XML-RPC, POP, IMAP
- Software Engineering - Unit Testing, Logging, Profiling, Parsing
- OS - Syscalls, Filesystems, TCP/IP Sockets
