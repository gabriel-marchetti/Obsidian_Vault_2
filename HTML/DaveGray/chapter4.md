# Lists Types:
Aqui foram comentados os usos de alguns tipos de listas, são elas as **Ordered Lists**, **Unordered Lists** e as **Description Lists**:

## Ordered Lists:
```html
<ol>
	<li> First Item. </li>
	<li> Second Item. </li>
	<li> Third Item. </li>
</ol>
```
## Unordered Lists:
```html
<ul>
	<li> First Item. </li>
	<li> Second Item. </li>
	<li> Third Item. </li>
</ul>
```
## Description Lists:
```html
<dl>
	<dt>North Pole</dt>
	<dd>This is a cold place</dd>
<dl>
```
