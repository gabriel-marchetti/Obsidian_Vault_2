A ideia desse vídeo é introduzir um currículo básico para desenvolvimento Web. Visto que diversos cursos de programação falham em introduzir todos os conhecimentos necessários para uma carreira.

# Conhecimentos Básicos:
## Recomendações Gerais:
É dito que uma possível referência para aprofundar em alguns conceitos é através do [Roadmap.sh](https://roadmap.sh/) que introduz de forma amigável a relação entre conhecimentos e os conhecimentos necessários.

Além disso, é importante saber que não é necessário saber tudo de uma vez só, contudo a área de programação exige estudo contínuo. A ideia é não aprender 100% dos conteúdos na primeira estudada, mas sim os 20% que resolverão 80% dos problemas.

## Version Control System:
**Pull Requests** e **Forks**.
git init, git add, git commit, git push, git pull -> o ultra-básico do version control system.

Algumas perguntas que precisam ser entendidas são:

O que é stage?
Para que serve squash de commits?

Para que serve reflog?
Diferença entre reset e clean?

## Projetos:
Precisamos de projetos para aplicar os conhecimentos adquiridos das ferramentas. Com uma errata grande, tutoriais apresentam passos irreais do desenvolvimento de software, eles foram pensados justamente como um passo ordenado de ações. Contudo na vida real não ocorre desse jeito.

Na vida real, na maioria absoluta dos casos você irá modificar código dos outros e participar de projetos que já existem. Muitos códigos são problemáticos. Tutoriais não ensinam a lidar com erros. 

Aqui há **uma ideia muito legal**, que consiste em pegar um repositório do github, como um clone do Instagram, e tentar rodar na sua máquina, você encontrará problemas.

## Basic Terminal Usage:
Esse e o SSH são conteúdos que mais são dificeis. Além disso, seja você desenvolvedor Backend ou Frontend, você precisará saber conhecimentos de Sistemas Operacionais. 

Instalar o VirtualBox e instalar distros linux. Toda CPU nova suporta Intel VT-X ou AMD-V, que fornecem performance para virtualização. 
Existem serviços "daemons" que são inicializados juntos do sistema operacional e conseguem executar comandos com um nível de autorização maior. Como controlar rede ou a rede de arquivos geral. "daemons" precisam de privilégios para conseguir operar.
