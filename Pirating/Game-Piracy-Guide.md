# qBitorrent:
- Options > Advanced > Network Interface > Set up your VPN (NordLynx for NordVPN).
- Turn off UTP protocol Options > Speed > Apply rate limit to uTP protocol (don't mark it).

# Downloading Torrent:
- There are two main ways of downloading Torrents: **.torrent files** and **Magnet Links**.
- Make sure to seed your files.
- Magnet Links works just by clicking them and setting it up for qBitorrent.
- .torrent files work installing them and opening them at qBitorrent.
# Type of Pirated Games:
- Scene Releases: normally .iso or many .rar files.
- Repacks: Download what you need from the internet and process decompression algorithm for the game.
- GOG Rips: Games that are rip from the drm-free game store GOG. Work the same way as GOG games.
- Pre-Installed Games: Easiest way to install pirated games.

## Scene Releases:
### gog-games (https://gog-games.to/)
- Copy the filehoster links.
- In Jdownloader2 - Right Click in the link grabber > Add new link > paste the links.
- Once download is complete. Goto destination folder and extract all folders.
- run the game.

### ova-games (https://ovagames.com/)
- Link download tab
- Choose file hoster of choice (best one is google drive).
- Filecrypt.co link
- See a list of parts
- Download all parts in the same folder
- Extract all files into the same folder
- Double click on the iso to mount it and run the setup
- Copy everything from inside the scene group name folder (eg: "Plaza" or "Codex") in the iso and paste it into the install directory.

### SteamRIP (https://steamrip.com/)
- Find the game and click the purple button that says "DOWNLOAD"
