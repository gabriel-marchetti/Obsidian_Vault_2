### Exemplo de documento de Game Design
Relembrando o formato de GDD apresentado em [[i-have-a-game-idea]] vamos relembrar a estrutura de **Concept Paper**, **Treatment Paper** e **GDD**.
**Concept Paper**: Escreva de modo interessante uma ou duas páginas sobre a ideia básica do jogo.
**Treatment Paper**: Escreva de 3 a 15 páginas sobre uma visão mais geral sobre o jogo.
**GDD**: Aqui temos uma descrição bem detalhada do jogo - podendo chegar de 50 a 300 páginas de descrição.
## Exemplo
Game Title: <game_name>
A game for <plataforms_that_will_run_this_game>
Copyright 2025 <insert_your_name>

"""
The main idea about a document like these is to excite and inform the reader.
The first page must be interesting, concise, informative and it must make the reader want to read the rest.
"""
Após a leitura da primeira página, o leitor deve conseguir visualizar alguns aspectos do jogo: Tente focar em mostrar o POV, como esse jogo será divertido e deixar clara a ideia do jogo.

-) GENERAL INFORMATION.
General description about the game, you need to create a mental image of your product to your reader. Using illustrations and pictures might help the reader to engage. 

-) DETAILED GAME DESCRIPTION.

- Qual é o conceito principal sendo introduzido dentro do jogo?
- Se aplicável, adicionar uma backstory. Como a narrativa se desenvolverá? 
- Qual o tom da história? Qual a narrativa principal? Qual o coração da história? A história será linear?
	Veja que essas perguntas são importantes, pois podem ditar o andamento do desenvolvimento do jogo. Pense no GTA IV que tem uma atmosfera bem mais pesada e densa do que seus antecessores, após assistir um vídeo sobre os produtores comentando esse aspecto, foi dito que essa atmosfera foi introduzida devido à problemas pessoas dos idealizadores.
	Desse modo, podemos perceber que essas perguntas todas foram respondidas nesse caso.
**OBJETIVO**:
- Qual é o objetivo do jogo? - Dentro do **GDD** defina esse objetivo claramente.
- Ganhar o máximo de pontos ainda server como descrição. Entretanto, isso irá gerar uma história diferente do que resgatar uma princesa, por exemplo.
- Qual o objetivo do jogador e porquê ele deveria jogar para realizar esse objetivo?
	Aqui podemos perceber que o objetivo do jogo define como os jogadores irão olhar para aquele jogo. Um jogo com propósito mais genérico, como um Subway Surfers, condiciona ao jogador uma postura específica. Se seu jogo envolve uma história mais profunda ou uma mecânica mais específica, então você precisará condicionar o jogador.
**GAMEPLAY**:
- Qual será a sequência de ações oferecidas ao jogador? Qual a consequência de escolher por uma das opções?
- Qual a interface planejada?
- Qual a perspectiva do jogo? (first-person or third-person)
- Qual a estrutura de interação com a narrativa? (Capítulos, Levels e por ai vai)
- Qual a principal característica da gameplay? (Speed, Action, Style, Continous, Turnbased, ...)
- Haverá Multiplayer? Se sim, como esse multiplayer se desenvolverá?
- Qual a dificuldade pensada para o jogo?
- Quanto tempo um jogador médio deve terminar o jogo?
- Como a IA se comportará dada uma ação do jogador?

-) OUTROS ASPECTOS DO JOGO:
**PERSONAGENS**:
- O jogador joga com um personagem?
- Descreva as habilidades, características e personalidades de cada personagem.
- Qual o personagem que o jogador joga? Existe mais de um personagem?
**EXPLORE QUESTÕES LEGAIS (SE APLICÁVEL)**:
- Um jogo de Star-Wars deve introduzir elementos desse universo. Portanto, se pergunte em que situações isso é adequado.
**DESCREVA SOBRE O MUNDO DENTRO DO JOGO:**
- O jogador conseguirá se mover livremente pelo mundo?
- O jogador tem uma rota otimizada para seguir? As barreiras irão parecer normais ou forçadas?
- Pense nas possíveis rotas que um jogador fará - Elas alteram o rumo da história?
**CONTROLES:**
- Descreva como os controles irão interferir no jogo?
- Descreva a interface para esses controles. Quais periféricos serão suportados?
- Como as mensagens de texto aparecerão dentro do jogo?
**DESCREVA A INTERFACE GRÁFICA DO JOGO:**
- A barra de vida será exposta?
- Os diálogos são desenvolvidos como?
- O jogador tem acesso a um inventário?
**DESCREVA SOBRE OS GRÁFICOS DO JOGO:**
- Referencie outros jogos que possuem gráfico similar.
- Esboce algumas cenas do jogo dentro do seu documento.
- Como os personagens irão se parecer?
	Não é necessário nessa parte se prender muito com o estilo de arte do jogo. Isso irá ocorrer naturalmente quando esse projeto puder subir para outro patamar.
**DESCREVA SOBRE OS SONS E MÚSICAS DENTRO DO JOGO.**
- Descreva como as músicas contribuem para a ambientação.
- Quais sons são importantes para indicar uma ação importante feita pelo jogador?
- Sons mais importantes devem ser priorizados a sons menos importantes.
